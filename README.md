# EZ6 EXT — Голосовой ассистент для Mazda EZ-6

[![Version](https://img.shields.io/github/v/release/Afflya/ez6ext?color=blue&label=Версия)](https://github.com/Afflya/ez6ext/releases)
[![License](https://img.shields.io/badge/Лицензия-Бесплатно-green.svg)](https://github.com/Afflya/ez6ext)
[![Offline](https://img.shields.io/badge/Офлайн-100%25-brightgreen.svg)](#офлайн-и-приватность)

**EZ6 EXT** — бесплатный голосовой ассистент для головного устройства (ГУ) автомобиля **Mazda EZ-6**, обеспечивающий прямое голосовое управление функциями автомобиля и вызов через штатную кнопку на руле.

---

## 📌 Ключевые особенности

- 🆓 **Абсолютно бесплатно**: Приложение распространяется на бесплатной основе.
- 🔒 **100% Офлайн и приватность**: Распознавание речи и исполнение команд происходят полностью на устройстве. Никакие голосовые или персональные данные не передаются на внешние сервера.
- ⚡ **Быстрый отклик**: Офлайн-модель распознавания речи (Vosk) обрабатывает команды мгновенно без задержек сети.
- 🚗 **Интеграция с автомобилем**: Работа с кнопкой микрофона на руле и системным распознаванием ключевой фразы (KWS).
- 🔄 **Автоматическое обновление**: Возможность проверки и установки новых версий приложения прямо из интерфейса.

## 🎙️ Как вызвать ассистента

Ассистента можно вызвать двумя способами:

1. **Кнопка на руле**: Нажмите штатную кнопку с иконкой микрофона на рулевом колесе.
2. **Голосовая активация (KWS)**: Произнесите ключевую фразу (например, `«Хай, Мазда»`).

> [!IMPORTANT]
> **Настройка системного ассистента в ГУ автомобиля:**
>
> Если вызов ассистента или распознавание ключевой фразы не работают, убедитесь, что соответствующие функции включены в штатных настройках авто:
> - **Вызов ассистента**: `Настройки авто` → `Голос` → `Интеллектуальный голос`
> - **Голосовая активация (KWS)**: `Настройки авто` → `Голос` → `Голосовое оповещение в салоне`

## 🔑 Запрашиваемые разрешения (Permissions)

Для полноценной и стабильной работы в фоновом режиме приложению запрашивает следующие рантайм-разрешения:

| Разрешение | Назначение |
| :--- | :--- |
| **Запись аудио (микрофон)**<br>`RECORD_AUDIO`, `FOREGROUND_SERVICE_MICROPHONE` | Необходимы для записи звука и локального распознавания речи и ключевой фразы (KWS). |
| **Отображение поверх других окон**<br>`SYSTEM_ALERT_WINDOW` | Требуется для отображения плавающего виджета ассистента и его статуса поверх любых приложений. |
| **Отключение оптимизации батареи**<br>`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Необходимо для предотвращения принудительного завершения фоновой службы системой Android. |
| **Фоновое обслуживание**<br>`FOREGROUND_SERVICE` | Гарантирует постоянную работу службы ассистента в фоне. |
| **Автозапуск при загрузке**<br>`RECEIVE_BOOT_COMPLETED` | Позволяет службе ассистента автоматически запускаться сразу при включении ГУ. |
| **Уведомления**<br>`POST_NOTIFICATIONS` | Показ сервисного уведомления о текущем состоянии ассистента. |
| **Установка пакетов**<br>`REQUEST_INSTALL_PACKAGES` | Требуется для скачивания и обновления приложения до актуальной версии из меню настроек. |
| **Сеть и Интернет**<br>`INTERNET`, `ACCESS_NETWORK_STATE` | Используются **исключительно** для проверки наличия и скачивания обновлений с GitHub. Голосовые команды обрабатываются без интернета! |

## 🔒 Офлайн и приватность

- **Без интернета**: Распознавание голоса и интерпретация команд работают полностью локально на базе библиотеки Vosk.
- **Приватность данных**: Приложение не ведет запись диалогов, не сохраняет и не отправляет аудиозаписи или телеметрию на сторонние серверы.
- **Связь с сетью**: Подключение к сети используется только при проверке обновлений на GitHub.

## 📦 Установка и обновление

1. Загрузите файл `.apk` из раздела [Releases](https://github.com/Afflya/ez6ext/releases).
2. Установите приложение на головное устройство вашего авто.
3. Запустите приложение и предоставьте запрашиваемые разрешения при первом старте.
4. В будущем обновления можно проверять и устанавливать прямо из приложения (раздел *«О приложении»*).
